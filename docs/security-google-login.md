# Googleログイン化（セキュリティ修正）手順書

2026-11-01 対応。対象：お金ちゃん／タスクマニア／カモの小屋／週の献立

## なぜ直したか

- 以前は、GAS の URL と合言葉（`VITE_API_TOKEN`）が公開 JS に埋め込まれていた。タスクマニアとカモの小屋には合言葉すらなかった
- そのため、サイトの JS を読めば誰でも GAS を直接呼び出せた。データの閲覧・上書きや、Claude API の利用ができてしまう状態だった

## 新しいしくみ

```
ブラウザ ──Googleログイン──▶ IDトークン（1時間有効）
   │
   └─ リクエストに id_token を付ける ──▶ GAS（Auth.gs）
                                         ├ Google に本物か問い合わせる
                                         ├ GOOGLE_CLIENT_ID と一致するか確認する
                                         └ ALLOWED_EMAILS に入っているか確認する
                                         → どれか1つでもダメなら "Unauthorized"
```

- `VITE_GOOGLE_CLIENT_ID` は公開されても問題ない値。秘密の値は、`VITE_` で始まる変数に入れてはいけない
- knak-lab.github.io 配下のアプリはログイン状態を共有する。1つのアプリでログインすれば、ほかのアプリでもログイン済みになる
- カモの小屋だけは、ほかの GAS（米チャレの収支取り込み）から呼ばれる道として `SERVICE_TOKEN` も受け付ける。この値はスクリプトプロパティにだけ置き、フロントには絶対に入れない

## 手順（PC で作業。全体で 40〜60 分）

### 1. Google Cloud で OAuth クライアント ID を作る（1回だけ・全アプリ共通）

1. https://console.cloud.google.com/ を開き、プロジェクトを作る（例：`knak-lab-apps`）
2. 「Google Auth Platform（OAuth 同意画面）」を設定する
   - アプリ名：knak-lab、ユーザーの種類：**外部**
   - サポートメールは自分のアドレスにする
   - 公開ステータスは「テスト」のままでよい。その場合は「テストユーザー」に自分と acco さんの Gmail を追加する
3. 「クライアント」→「クライアントを作成」を開く
   - 種類：**ウェブ アプリケーション**
   - 承認済みの JavaScript 生成元：
     - `https://knak-lab.github.io`
     - `http://localhost:5173`
     - `http://localhost`
   - リダイレクト URI は不要
4. 表示された **クライアント ID**（`xxxx.apps.googleusercontent.com`）を控える

### 2. 各 GAS のスクリプトプロパティを設定する（4 アプリそれぞれ）

GAS エディタ → ⚙プロジェクトの設定 → スクリプト プロパティ

| プロパティ | 値 | 対象 |
|---|---|---|
| `GOOGLE_CLIENT_ID` | 手順 1 のクライアント ID | 4 アプリすべて |
| `ALLOWED_EMAILS` | `自分のGmail,accoさんのGmail`（カンマ区切り） | 4 アプリすべて |
| `SERVICE_TOKEN` | 32 文字以上のランダムな文字列（下の作り方を参照） | カモの小屋のみ |
| `API_TOKEN` | **削除する**（もう使わない） | お金ちゃん・週の献立・カモの小屋 |

ランダムな文字列は、ターミナルで次のコマンドを実行して作る。

```
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### 3. GAS にコードを反映して、再デプロイする（4 アプリそれぞれ）

```
git pull
clasp push
```

> ⚠ **カモの小屋は先に確認すること**：米チャレが呼んでいる `action=komechalleExport` の処理が、リポジトリのコードにはありません。GAS エディタ上にだけ書いてある場合、`clasp push` で消えてしまいます。エディタで `komechalleExport` を検索し、見つかったらリポジトリにコピーしてから push してください。

1. GAS エディタで関数 `authSelfCheck` を選んで「実行」する
   - 外部サービスへの接続の許可を求められるので、許可する
   - ログに「GOOGLE_CLIENT_ID: 設定済み」「ALLOWED_EMAILS: ○○」と出れば OK
2. 「デプロイ」→「デプロイを管理」→ 今のデプロイの ✏ 編集 → バージョン「新バージョン」→「デプロイ」
   - URL は変わらないので、`.env.local` の `VITE_GAS_URL` はそのままでよい

**このあと手順 4 が終わるまで、そのアプリは使えなくなります（＝穴が閉じた状態）。**

### 4. フロントを再ビルドして公開する（4 アプリそれぞれ）

`.env.local` を次のように直す。

```
# 削除
VITE_API_TOKEN=...
# 追加
VITE_GOOGLE_CLIENT_ID=手順1のクライアントID
```

```
npm install
npm run deploy
```
